### 🚀 Featured Engineering Highlights
*Note: Source codes for enterprise projects are kept private under NDA. Below are architectural summaries of my key implementations.*

#### 1. VFP to Postgres ETL & Enterprise Dashboard
Engineered a bulletproof ETL pipeline bridging legacy Visual FoxPro databases (`.DBF`) to PostgreSQL. 
* **Key Architecture:** Implemented batch processing (chunking) for massive datasets to prevent Node.js Out-of-Memory (OOM) errors.
* **Bypass Mechanisms:** Devised a dual-engine Excel export strategy (Server-side Node.js & Client-side React) and timezone-agnostic date parsers to handle legacy data anomalies.

#### 2. Local Intelligent Document Processing (IDP)
Developed a privacy-first document analysis suite that runs 100% offline.
* **Key Architecture:** Hybrid extraction utilizing `Tesseract OCR` for embedded images and local LLM (`qwen2.5:3b` via Ollama) for intelligent data matching (e.g., reconciling PO Numbers from transfer receipts).

#### 3. ERP Automation Suite & Legacy Modernization
Built robust RPA scripts to bypass manual data entry bottlenecks on legacy desktop ERPs.
* **Key Architecture:** Created a custom data extraction module bypassing memory-based Volume ID (Vol-ID) licensing. Deployed smart cursor strategies for auto-auditing multi-tier discounts and taxes.
